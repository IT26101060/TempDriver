MODULE PACKAGE: Lesson Scheduling & Queue

This ZIP contains this module's servlet plus shared file-storage utility and JSP.
For a working web application, use the unified DrivingSchoolSystem_FullProject.zip
because it includes all six modules and the complete Maven structure.

Build/run:
1. Open the full project ZIP extracted folder in IntelliJ as Maven.
2. Set JDK 17.
3. Maven Reload, then package.
4. Deploy target/DrivingSchoolSystem.war to Tomcat 10.1/webapps.
